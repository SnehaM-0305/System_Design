# System Design Practice

This repository contains my **System Design practice and implementations**.

I use this repository to learn and practice **Low-Level Design (LLD)** concepts by designing different real-world systems and implementing them in Java.

## 📁 Repository Structure

Each folder focuses on **one System Design problem**.

A typical folder contains:

```text
System_Design/
│
├── ParkingLot/
│   ├── FunctionalRequirements.txt
│   ├── *.java
│   └── UML.png
│
├── TaskManagement/
│   ├── FunctionalRequirements.txt
│   ├── *.java
│   └── UML.png
│
├── LoggingFramework/
│   ├── FunctionalRequirements.txt
│   ├── *.java
│   └── UML.png
│
└── ...
```

### Each System Design Folder Contains

* **FunctionalRequirements.txt** — Functional requirements and assumptions for the system.
* **Java Code** — Object-oriented implementation of the design.
* **UML Diagram** — Visual representation of classes, relationships, and interactions.

## 🎯 Goals

The main goals of this repository are:

* Practice **Low-Level System Design (LLD)**
* Improve **Object-Oriented Design** skills
* Understand and apply **SOLID principles**
* Practice commonly used **Design Patterns**
* Convert requirements into classes and relationships
* Improve UML diagramming skills
* Implement designs using **Java**
* Prepare for **LLD/System Design interviews**

## 🛠️ Tech Stack

* **Language:** Java
* **Design:** UML
* **Concepts:** OOP, SOLID, Design Patterns, LLD

## 📚 Systems Practiced

Some of the systems covered/practiced in this repository include:

* Parking Lot
* Task Management System
* Logging Framework
* Traffic Signal
* And more to come...

This repository is continuously updated as I practice and design new systems.

## 🚀 Approach

For each problem, I generally follow this process:

```text
Requirements
     ↓
Identify Entities
     ↓
Define Classes & Responsibilities
     ↓
Define Relationships
     ↓
Create UML Diagram
     ↓
Implement in Java
     ↓
Review Design & Improve
```

## 📌 Purpose

This is primarily a **learning and interview-preparation repository** where I experiment with different approaches to designing real-world systems and improve my LLD skills through hands-on implementation.
